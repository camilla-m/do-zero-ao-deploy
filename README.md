# Descomplicando DevOps & Cloud — Zero ao Deploy

Repositório oficial do curso: material de aula, roteiros e exercícios práticos, organizados módulo a módulo.

## Como usar este repositório

- Cada módulo tem sua própria pasta numerada (`01-fundamentos`, `02-cloud-iac`, ...).
- Cada aula é uma subpasta com um `README.md` (roteiro da aula) e uma pasta `exercicio/` (enunciado prático).
- Siga a ordem numérica — o curso é construído em camadas, do terminal até o deploy em produção.
