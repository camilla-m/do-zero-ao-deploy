# Pré-requisitos

Antes da Aula 1, tenha instalado e funcionando:

- [ ] Git
- [ ] Um editor de código (recomendado: VS Code)
- [ ] Terminal Linux/WSL (Windows) ou terminal nativo (macOS/Linux)
- [ ] Docker
- [ ] Terraform
- [ ] kubectl
- [ ] Uma ferramenta de cluster local: kind ou minikube
- [ ] Conta criada no provedor de nuvem que o curso vai usar

Não precisa saber usar nada disso ainda — só ter instalado. A gente aprende a usar ao longo do curso.
