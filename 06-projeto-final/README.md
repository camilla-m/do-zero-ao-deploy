# Módulo 6 — Projeto Final

## Aulas

1. Planejamento do projeto — escolhendo a aplicação, desenhando a arquitetura, definindo escopo realista.
2. Infraestrutura do projeto final — provisionando toda a base com Terraform.
3. Containerização e Kubernetes do projeto final.
4. Pipeline de CI/CD completo — do commit ao deploy, sem intervenção manual.
5. Observabilidade do projeto final — métricas, dashboard e ao menos um alerta.
6. Apresentação e feedback — cada aluno apresenta o projeto rodando.

## Entrega

Use a pasta [`template/`](template/) como ponto de partida pro seu projeto final.
Critérios de avaliação em [`criterios-avaliacao.md`](criterios-avaliacao.md).
