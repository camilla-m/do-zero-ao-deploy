# Template — Projeto Final

Use esta pasta como esqueleto inicial pro seu projeto. Estrutura sugerida:

```
meu-projeto-final/
├── README.md
├── infra/          # código Terraform
├── app/            # código da aplicação
├── k8s/            # manifests ou Helm chart
├── .github/
│   └── workflows/  # pipeline de CI/CD
└── observabilidade/
    └── dashboards/
```
