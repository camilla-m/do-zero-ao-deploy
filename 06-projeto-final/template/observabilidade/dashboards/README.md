# observabilidade/dashboards/

Exporte seu dashboard do Grafana (Dashboard settings → JSON Model, ou via `GET
/api/dashboards/uid/<uid>`, como no Módulo 5, Aula 03) e salve aqui como `dashboard.json`.

Salve também, num `alertas.md` ou similar, a regra de alerta que você testou disparando de
verdade (Módulo 5, Aula 04) — com a evidência (log/print/saída de `curl`) de que ela disparou e
voltou a limpar.
